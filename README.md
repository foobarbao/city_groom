# City Groom

Application mobile (Android + version web installable) — **en phase de
démonstration**, conçue pour servir de base à une future version de production.

> ⚠️ Le code applicatif n'est pas encore initialisé. Ce dépôt contient pour
> l'instant les règles de codage, le workflow et les premières décisions
> d'architecture.

## Stack (proposée)

Vue 3 + TypeScript + Ionic + Capacitor, bâti avec Vite. Un seul code produit :

- une **PWA** (web app installable) pour la diffusion aux testeurs ;
- un **APK Android** pour les fonctionnalités natives et la future publication.

Détails et alternatives écartées : [ADR-0002](docs/adr/0002-choix-stack-mobile.md).
